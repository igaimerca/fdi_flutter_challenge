## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/igaimerca/fdi_flutter_challenge.git
   cd fdi_flutter_challenge
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```
